# Summer 2026: Family Trip Comparison

A static single-page website comparing two family vacation options (Charleston + Kiawah vs Keys + Everglades) for Summer 2026.

## Project Structure

- `index.html` — The entire site (self-contained HTML/CSS/JS, no build step needed)
- `docs/plans/` — Supporting planning documents

## Running the App

Served via Python's built-in HTTP server on port 5000:

```
python3 -m http.server 5000
```

## Deployment

Configured as a static site deployment with the root directory (`.`) as the public directory.
