## 5. Web Application & State Synchronization

The repository runs a lightweight Python REST server (`server.py`) serving `index.html` (and `montreal.html`) on port 5050 locally and on Replit.

* **State File:** `/Users/Michael/Projects/family-trip/data/montreal_state.json`
* **Backup Mirror:** `/Users/Michael/Projects/family-trip/data/montreal_state.backup.json` (un-tracked by Git to prevent clobbering).
* **PIN Protection:** Admin controls are protected by PIN `2026` (or env `ADMIN_PIN`).

### How to Update the App Once a Reservation Confirms:
When an email reply confirms a table, update the schedule in `data/montreal_state.json`:
1. Change `dinner_status` from `"voting"` or `"target"` to `"confirmed"`.
2. Update `dinner` with the confirmed venue name and time (e.g. `"Rosélys at Fairmont (Confirmed 6:00 PM)"`).
3. Add confirmation notes, reservation numbers, deposit info, and cancellation deadlines to `dinner_note`.
4. Run `cp index.html montreal.html`, commit, and push to GitHub.
